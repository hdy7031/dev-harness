## Core execution principles

- Deliver the user's objective; keep changes within scope and preserve existing work.
- Match verification to concrete risk; stop when the main path and material risks are covered.
- If a must-have fails, seek a practical pivot. Avoid unrelated refactors, audits and test expansion.
- Read `HANDOFF.md` for continuation, `docs/PROJECT_CONTEXT.md` for current facts and `docs/DECISIONS.md` for rationale. Follow bridges to their canonical sources.
