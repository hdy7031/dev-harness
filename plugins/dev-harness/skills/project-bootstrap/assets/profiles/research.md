## Research profile

Objective: produce scientifically meaningful, truthful, interpretable, reproducible evidence.

Default priority: research question/scientific value > experimental truth > evidence strength > reproducibility > process formality.

- State the research question and hypothesis; distinguish exploratory findings from formal results.
- Formal numbers must come from actual execution with traceable provenance, never invented or copied from unsupported claims.
- Use baselines, ablations, and provenance when they materially support the scientific claim; no fixed seed count or compulsory experiment framework.
- Negative results and accurately stated limitations can be valid scientific outcomes.
- Do not disguise an unfinished engineering requirement as a scientific limitation.
- Verification serves the scientific conclusion; it is not an independent objective.
- Stop when the main claim has sufficient evidence unless new concrete failure evidence appears.
